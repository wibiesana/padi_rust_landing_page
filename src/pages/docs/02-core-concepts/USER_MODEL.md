## 🛠️ Concrete Model & Business Logic (`app/Models/User.go`)

Place your custom business logic, password hashing, and role inspection methods here:

```go
package models

import (
	base "padi-template/app/Models/Base"
	"github.com/wibiesana/padi_go_core/auth"
)

type User struct {
	base.User
}

// SetPassword securely hashes the plain text password
func (u *User) SetPassword(plain string) error {
	hash, err := auth.HashPassword(plain)
	if err != nil {
		return err
	}
	u.Password = hash
	return nil
}

// VerifyPassword checks if plain text password matches the bcrypt hash
func (u *User) VerifyPassword(plain string) bool {
	return auth.VerifyPassword(u.Password, plain)
}

// IsActive checks if the user account is active
func (u *User) IsActive() bool {
	return u.Status == "active"
}

// HasRole checks if the user possesses a specific role
func (u *User) HasRole(role string) bool {
	return u.Role == role
}
```

## 🔒 Security & Password Protection

- **JSON Tag `json:"-"`**: The `password` field is automatically excluded from all HTTP responses (`response.Item`, `response.Items`, `response.Paginated`) via the struct tag.
- **`HideFields` runtime protection**: For additional runtime guarantee — or for fields that use `json:",omitempty"` rather than `json:"-"` — call `activerecord.HideFields` to zero-out sensitive fields before serialization:

```go
// The User model implements Hidden() to declare sensitive fields
func (User) Hidden() []string {
    return []string{"password", "remember_token"}
}

// In controllers: zero-out hidden fields before returning
users, _ := activerecord.All[models.User]()
activerecord.HideFields(&users)
response.Items(w, users, "Users list")
```

- **Bcrypt Hashing**: Passwords are saved with standard bcrypt cost factors using `auth.HashPassword`.

## 🗂️ Database Schema

```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(255) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL,
    role VARCHAR(50) DEFAULT 'user',
    status VARCHAR(20) DEFAULT 'active',
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL
);
```

## ✨ Best Practices

1. **Always use `SetPassword()`**: Never assign plain text strings directly to `u.Password`.
2. **Inspect Status on Login**: Reject authentication if `!user.IsActive()`.
3. **Use Generic Queries**:
   ```go
   user, err := activerecord.FindOrFail[models.User](id)
   ```
4. **Declare `Hidden()` on sensitive models**: Return field names like `"password"` and `"remember_token"` from `Hidden() []string`, then call `activerecord.HideFields` in list/detail controllers to guarantee zero data leakage regardless of JSON tag configuration.
