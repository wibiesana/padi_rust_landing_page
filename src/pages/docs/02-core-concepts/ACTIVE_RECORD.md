## 📦 Model Architecture

Padi uses a clean, two-tier model separation:

### 1. Base Model (`app/Models/Base/Article.go`)
*Auto-generated and overwritten whenever your database schema changes.*

```go
// Code generated by Padi Generator. DO NOT EDIT.

	"time"
	"github.com/wibiesana/padi_go_core/activerecord"
)

type Article struct {
	ID        uint       `db:"id" json:"id"`
	Title     string     `db:"title" json:"title" validate:"required"`
	Content   string     `db:"content" json:"content" validate:"required"`
	AuthorID  uint       `db:"author_id" json:"author_id"`
	CreatedAt *time.Time `db:"created_at" json:"created_at"`
	UpdatedAt *time.Time `db:"updated_at" json:"updated_at"`
}

func (Article) TableName() string {
	return "articles"
}

func (Article) PrimaryKey() string {
	return "id"
}

func (Article) Fillable() []string {
	return []string{"title", "content", "author_id"}
}

func (Article) Relations() map[string]activerecord.Relation {
	return map[string]activerecord.Relation{
		"author": activerecord.BelongsTo("users", "author_id", "id"),
	}
}
```

## 🔍 Reading Data & Eager Loading

### Out-of-the-Box Eager Loading (`.With()`)
Padi provides high-performance eager loading with support for multi-level nested relations (`comments.author`) and column filtering (`author:id,name`):

```go
// 1. Fetch articles with author and comments in optimized batch queries
articles, err := activerecord.NewModelQuery[models.Article]().
    With("author:id,name,email", "comments.author").
    Where("status", "published").
    OrderBy("created_at", "DESC").
    Get()

for _, article := range articles {
    if author, ok := article.GetRelation("author").(*models.User); ok && author != nil {
        fmt.Println("Author:", author.Name)
    }
}

// 2. Paginate with Eager Loading
opts := query.ParseOptions(r)
articles, meta, err := activerecord.NewModelQuery[models.Article]().
    With("author", "comments").
    Paginate(opts, []string{"title", "content"})

// 3. Paginate returning Maps (ready for JSON serialization)
dataMaps, meta, err := activerecord.NewModelQuery[models.Article]().
    With("author", "comments.author").
    PaginateMaps(opts, []string{"title"})
```

### Find by ID
```go
article, err := activerecord.Find[models.Article](1)
if err != nil || article == nil {
    // Record not found
}
```

### Find with Error on Not Found
```go
article, err := activerecord.FindOrFail[models.Article](1)
```

### Find All / List
```go
// 1. Fetch all records without filters
articles, err := activerecord.All[models.Article]()

// 2. Fetch all records with search & sorting options
opts := query.ParseOptions(r) // or custom query.Options{Search: "Go", Sort: "created_at", Order: "DESC"}
articles, err := activerecord.AllWithOpts[models.Article](opts, "title", "content")
```

### Paging & Search
```go
opts := query.Options{
    Page:    1,
    PerPage: 15,
    Search:  "Framework",
    Sort:    "id",
    Order:   "DESC",
}

meta, articles, err := activerecord.Paginate[models.Article](opts, "title", "content")
// Returns: meta (Pagination struct), articles ([]models.Article)
```

## 🚀 Full End-to-End Controller Example

Berikut adalah contoh kode lengkap (**Full Code**) sebuah Controller REST API yang menerapkan pencarian (*search*), pengurutan (*sorting*), paginasi (*pagination*), *get all with options*, dan operasi CRUD lengkap menggunakan ActiveRecord:

```go
package controllers

import (
	"net/http"

	models "padi-template/app/Models"
	"github.com/wibiesana/padi_go_core/activerecord"
	"github.com/wibiesana/padi_go_core/query"
	"github.com/wibiesana/padi_go_core/response"
	"github.com/wibiesana/padi_go_core/router"
	"github.com/wibiesana/padi_go_core/validator"
)

type ArticleController struct{}

func NewArticleController() *ArticleController {
	return &ArticleController{}
}

// 1. Index: GET /articles?page=1&per_page=15&search=golang&sort=id&order=desc&with=author,comments
func (c *ArticleController) Index(w http.ResponseWriter, r *http.Request) {
	opts := query.ParseOptions(r)
	searchColumns := []string{"title", "content"}

	meta, articles, err := activerecord.PaginateWithContext[models.Article](r.Context(), opts, searchColumns...)
	if err != nil {
		response.InternalServerError(w, "Gagal mengambil daftar artikel")
		return
	}

	// One-liner eager loading from ?with= query param
	_ = activerecord.LoadRelationsFromRequest(r, &articles)

	response.Paginated(w, articles, meta, "Daftar artikel berhasil diambil")
}

// 2. All: GET /articles/all?search=golang&sort=created_at&order=desc&with=author
func (c *ArticleController) All(w http.ResponseWriter, r *http.Request) {
	opts := query.ParseOptions(r)
	searchColumns := []string{"title", "content"}

	articles, err := activerecord.AllWithOptsWithContext[models.Article](r.Context(), opts, searchColumns...)
	if err != nil {
		response.InternalServerError(w, "Gagal mengambil semua artikel")
		return
	}

	_ = activerecord.LoadRelationsFromRequest(r, &articles)

	response.Items(w, articles, "Semua artikel berhasil diambil")
}

// 3. Show: GET /articles/{id}?with=author,comments.user
func (c *ArticleController) Show(w http.ResponseWriter, r *http.Request) {
	id, err := router.ParamUint(r, "id")
	if err != nil {
		response.BadRequest(w, "ID tidak valid")
		return
	}

	// FindOrFail: returns error if not found — no separate nil check needed
	article, err := activerecord.FindOrFail[models.Article](id)
	if err != nil {
		response.NotFound(w, "Artikel tidak ditemukan")
		return
	}

	// One-liner eager loading from ?with= query param
	_ = activerecord.LoadRelationsFromRequest(r, article)

	response.Item(w, article, "Artikel berhasil ditemukan")
}

// 4. Store: POST /articles
func (c *ArticleController) Store(w http.ResponseWriter, r *http.Request) {
	var input struct {
		Title    string `json:"title" validate:"required,min=3,max=255"`
		Content  string `json:"content" validate:"required"`
		AuthorID uint   `json:"author_id" validate:"required"`
	}

	// Validasi input JSON
	if errs, err := validator.BindJSON(r, &input); err != nil {
		response.UnprocessableEntity(w, "Validasi gagal", errs)
		return
	}

	// Inisialisasi model baru
	article := models.Article{}
	article.Title = input.Title
	article.Content = input.Content
	article.AuthorID = input.AuthorID

	// Save otomatis mengisi created_at, updated_at, dan created_by dari JWT context
	if err := activerecord.Save(&article, r.Context()); err != nil {
		response.InternalServerError(w, "Gagal membuat artikel")
		return
	}

	response.Created(w, article, "Artikel berhasil dibuat")
}

// 5. Update: PUT /articles/{id}
func (c *ArticleController) Update(w http.ResponseWriter, r *http.Request) {
	id, err := router.ParamUint(r, "id")
	if err != nil {
		response.BadRequest(w, "ID tidak valid")
		return
	}

	article, err := activerecord.FindWithContext[models.Article](r.Context(), id)
	if err != nil || article == nil {
		response.NotFound(w, "Artikel tidak ditemukan")
		return
	}

	var input struct {
		Title   *string `json:"title" validate:"omitempty,min=3,max=255"`
		Content *string `json:"content"`
	}

	if errs, err := validator.BindJSON(r, &input); err != nil {
		response.UnprocessableEntity(w, "Validasi gagal", errs)
		return
	}

	if input.Title != nil {
		article.Title = *input.Title
	}
	if input.Content != nil {
		article.Content = *input.Content
	}

	// Save update record yang ada (updated_at & updated_by terisi otomatis)
	if err := activerecord.Save(article, r.Context()); err != nil {
		response.InternalServerError(w, "Gagal mengupdate artikel")
		return
	}

	response.Item(w, article, "Artikel berhasil diperbarui")
}

// 6. Destroy: DELETE /articles/{id}
func (c *ArticleController) Destroy(w http.ResponseWriter, r *http.Request) {
	id, err := router.ParamUint(r, "id")
	if err != nil {
		response.BadRequest(w, "ID tidak valid")
		return
	}

	article, err := activerecord.FindWithContext[models.Article](r.Context(), id)
	if err != nil || article == nil {
		response.NotFound(w, "Artikel tidak ditemukan")
		return
	}

	// Hapus record (menjalankan hook BeforeDelete & AfterDelete jika ada)
	if err := activerecord.DeleteModel(article); err != nil {
		response.InternalServerError(w, "Gagal menghapus artikel")
		return
	}

	response.Success(w, "Artikel berhasil dihapus", nil)
}
```

## ✏️ Writing Data

### Save (Insert or Update Automatically)
`Save` determines whether to `INSERT` or `UPDATE` based on the primary key:

```go
// 1. Insert New Record (ID is 0)
newArticle := models.Article{}
newArticle.Title = "New Title"
newArticle.Content = "New Content"
err := activerecord.Save(&newArticle) // newArticle.ID is populated

// 2. Update Existing Record (ID > 0)
existing, _ := activerecord.Find[models.Article](1)
existing.Title = "Updated Title"
err = activerecord.Save(existing)
```

### Batch Insert
```go
items := []models.Article{
    {Title: "Article 1", Content: "Content 1"},
    {Title: "Article 2", Content: "Content 2"},
}
err := activerecord.BatchInsert(items)
```

### Update Specific Columns
```go
err := activerecord.Update[models.Article](1, map[string]interface{}{
    "title": "New Title",
    "status": "published",
})
```

### Delete / Soft Delete
```go
// Delete by ID
err := activerecord.Delete[models.Article](1)

// Delete by Model reference
err = activerecord.DeleteModel(existingArticle)
```

## 🙈 Hidden / Sensitive Fields (`HideFields`)

Models can mark fields as hidden to prevent them from appearing in JSON responses. This is particularly useful for sensitive data like passwords or tokens.

### Implement the `Hidden()` interface

```go
package models

type User struct {
    base.User
}

// Hidden lists field names to zero-out before serialization.
// Matched by db tag, json tag, or struct field name.
func (User) Hidden() []string {
    return []string{"password", "remember_token"}
}
```

### Apply in a controller

```go
// Strip hidden fields from a collection before returning
users, _ := activerecord.All[models.User]()
activerecord.HideFields(&users)
response.Items(w, users, "Users list")

// Or on a single record
user, _ := activerecord.FindOrFail[models.User](id)
activerecord.HideFields(user)
response.Item(w, user, "User detail")
```

> **Note**: Fields are zeroed in-place using reflection. Ensure the struct field has `json:",omitempty"` or `json:"-"` tag if you want it completely absent from JSON output, or simply zero-value fields will be omitted when `omitempty` is set.

## 🪝 Lifecycle Hooks

Models can implement lifecycle hook interfaces:

```go
// BeforeSave executes before INSERT or UPDATE
func (m *Article) BeforeSave(isInsert bool) error {
    if isInsert && m.Status == "" {
        m.Status = "draft"
    }
    return nil
}

// AfterSave executes after INSERT or UPDATE
func (m *Article) AfterSave(isInsert bool) {
    log.Printf("Article #%d saved (isInsert: %v)", m.ID, isInsert)
}

// BeforeDelete executes before DELETE
func (m *Article) BeforeDelete() error {
    log.Printf("Deleting article #%d...", m.ID)
    return nil
}

// AfterDelete executes after DELETE
func (m *Article) AfterDelete() {
    log.Printf("Article deleted")
}
```

## 🕒 Automated Audit Trail & Timestamps

Padi Go Framework includes built-in, industrial-grade **Audit Trail & Blameable Behavior** similar to the classic PHP Padi framework.

### ⚡ How It Works

When executing `activerecord.Save(m, r.Context())`:

1. **On INSERT (`Create` / `Store`)**:
   - `created_at` and `updated_at` are automatically populated with the current UTC timestamp (`time.Now().UTC()`).
   - If the request is authenticated, `created_by` and `updated_by` are automatically filled with the logged-in User ID extracted from the JWT session.
2. **On UPDATE**:
   - `updated_at` is automatically updated to the current UTC timestamp.
   - `updated_by` is updated with the active User ID making the modification.
   - `created_at` and `created_by` remain immutable.

---

### ⚙️ Configuration & Customization

#### 1. Turning Audit Trail On / Off
By default, audit behavior is enabled. To disable auto-timestamps and blameable fields for a specific model, implement `UseAudit() bool`:

```go
package models

type Setting struct {
    base.Setting
}

// Turn off auto-audit for this model
func (Setting) UseAudit() bool {
    return false
}
```

#### 2. Custom Column Mappings
If your database schema uses custom column names (e.g. `tgl_dibuat`, `pembuat_id`), implement `AuditFields() map[string]string`:

```go
package models

type Transaction struct {
    base.Transaction
}

func (Transaction) AuditFields() map[string]string {
    return map[string]string{
        "created_at": "tgl_transaksi",
        "updated_at": "tgl_update",
        "created_by": "kasir_id",
        "updated_by": "editor_id",
    }
}
```

> **Tip**: You can selectively disable specific fields by assigning an empty string:
> ```go
> func (Transaction) AuditFields() map[string]string {
>     return map[string]string{
>         "created_at": "created_at",
>         "updated_at": "updated_at",
>         "created_by": "", // Disable created_by
>         "updated_by": "", // Disable updated_by
>     }
> }
> ```

### 🗓️ Choosing Timestamp Format: `DATETIME` vs `INTEGER`

Padi ActiveRecord dynamically adapts to your Go struct field types:

| Desired DB Format | Go Struct Type | Example Output |
| :--- | :--- | :--- |
| **`DATETIME` / `TIMESTAMP`** | `time.Time` or `*time.Time` | `"2026-09-01T20:00:00Z"` |
| **`INTEGER` (UNIX Epoch Seconds)** | `int64`, `*int64`, `int`, `uint` | `1788266861` |

```go
// Example: Using Integer UNIX Timestamps
type Product struct {
    ID        uint    `db:"id" json:"id"`
    Name      string  `db:"name" json:"name"`
    CreatedAt *int64  `db:"created_at" json:"created_at"`
    UpdatedAt *int64  `db:"updated_at" json:"updated_at"`
    CreatedBy *uint   `db:"created_by" json:"created_by"`
    UpdatedBy *uint   `db:"updated_by" json:"updated_by"`
}
```
