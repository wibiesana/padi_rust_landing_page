# 📦 API Resources & Transformation Guide

## 💎 Elegant Data Transformation & Presentation Layer

**API Resources** in Padi Go Framework provide a dedicated transformation layer between your database models and the JSON response sent to client applications.

Like Models and Controllers, Resources use a two-tier **Base & Concrete** architecture:
1. **`app/Resources/Base/<Model>Resource.go`**: Auto-generated by the CLI based on your table schema (always kept up-to-date with database columns).
2. **`app/Resources/<Model>Resource.go`**: Generated once. You can freely customize fields, format dates, calculate values, or inject nested relationships. **It is NEVER overwritten during scaffolding/regeneration.**

## 🏗️ Resource Architecture

### 1. Base Resource (`app/Resources/Base/ArticleResource.go`)
*Auto-generated. Overwritten whenever the database schema is regenerated.*

```go
// Code generated by Padi Generator. DO NOT EDIT.
package base

import (
	models "padi-template/app/Models"
)

type ArticleResource struct{}

// ToMap converts a single model instance to a map
func (r *ArticleResource) ToMap(item *models.Article) map[string]interface{} {
	if item == nil {
		return nil
	}
	return map[string]interface{}{
		"id":         item.ID,
		"title":      item.Title,
		"content":    item.Content,
		"author_id":  item.AuthorID,
		"created_at": item.CreatedAt,
		"updated_at": item.UpdatedAt,
	}
}

// ToMapCollection converts a slice of models to a slice of maps
func (r *ArticleResource) ToMapCollection(items []models.Article) []map[string]interface{} {
	if items == nil {
		return []map[string]interface{}{}
	}
	result := make([]map[string]interface{}, len(items))
	for i := range items {
		result[i] = r.ToMap(&items[i])
	}
	return result
}
```

### 2. Concrete Resource (`app/Resources/ArticleResource.go`)
*Generated once. Place your custom transformations and relations here. Safe from overwrites.*

```go
package resources

import (
	models "padi-template/app/Models"
	base "padi-template/app/Resources/Base"
	"github.com/wibiesana/padi_go_core/activerecord"
	"github.com/wibiesana/padi_go_core/query"
)

type ArticleResource struct {
	base.ArticleResource
}

func NewArticleResource() *ArticleResource {
	return &ArticleResource{}
}

// ToMap transforms a single model. Add custom fields or relations here.
func (r *ArticleResource) ToMap(item *models.Article) map[string]interface{} {
	// 1. Get default base field mapping
	data := r.ArticleResource.ToMap(item)
	if data == nil {
		return nil
	}

	// 2. Include nested Author relationship
	if item.AuthorID > 0 {
		if author, _ := activerecord.Find[models.User](item.AuthorID); author != nil {
			data["author"] = map[string]interface{}{
				"id":    author.ID,
				"name":  author.Name,
				"email": author.Email,
			}
		}
	}

	// 3. Include nested Comments
	var comments []models.Comment
	_ = query.New("comments").Where("article_id", item.ID).All(&comments)
	data["comments"] = comments

	return data
}
```

## ⚙️ CLI Scaffolding Behavior

When you run:

```bash
go run cmd/padi/main.go g articles
```

The Padi CLI Generator will:
1. **Regenerate `app/Resources/Base/ArticleResource.go`**: updates any newly added or deleted database columns.
2. **Check `app/Resources/ArticleResource.go`**:
   - If it **does not exist**, it generates the starter concrete resource file.
   - If it **already exists**, it skips the file, **preserving all your custom transformations and relationships**.

> ℹ️ **Protected Tables**: Core system tables (`users`, `password_resets`, `migrations`, `jobs`) are protected and do not generate default resource files to prevent overriding core auth logic.

## 🎮 Controller Integration

Controllers generated by Padi use Resources by default in all responses:

```go
func (c *ArticleController) Show(w http.ResponseWriter, r *http.Request) {
	id, _ := router.ParamUint(r, "id")
	item, err := activerecord.Find[models.Article](id)
	if err != nil || item == nil {
		response.NotFound(w, "Article not found")
		return
	}

	res := resources.NewArticleResource()
	response.Item(w, res.ToMap(item), "Article retrieved successfully")
}

func (c *ArticleController) Index(w http.ResponseWriter, r *http.Request) {
	opts := query.ParseOptions(r)
	meta, records, _ := activerecord.Paginate[models.Article](opts, "title")

	res := resources.NewArticleResource()
	response.Paginated(w, res.ToMapCollection(records), meta, "Article list retrieved")
}
```

## 💡 Practical Customization Examples

### 1. Injecting Relationships (`BelongsTo`, `HasMany`)
```go
func (r *ProductResource) ToMap(item *models.Product) map[string]interface{} {
	data := r.ProductResource.ToMap(item)
	if data == nil {
		return nil
	}

	if category, _ := activerecord.Find[models.Category](item.CategoryID); category != nil {
		data["category"] = category
	}

	return data
}
```

### 2. Formatting Values & Currency
```go
func (r *InvoiceResource) ToMap(item *models.Invoice) map[string]interface{} {
	data := r.InvoiceResource.ToMap(item)
	if data == nil {
		return nil
	}

	// Format currency
	data["amount_formatted"] = fmt.Sprintf("IDR %d", item.Amount)

	// Format human-friendly date
	if item.CreatedAt != nil {
		data["formatted_date"] = item.CreatedAt.Format("02 January 2006")
	}

	return data
}
```

### 3. Data Masking & Computed Fields
```go
func (r *CustomerResource) ToMap(item *models.Customer) map[string]interface{} {
	data := r.CustomerResource.ToMap(item)
	if data == nil {
		return nil
	}

	// Mask phone number: e.g. 0812****7890
	if len(item.Phone) > 6 {
		data["phone_masked"] = item.Phone[:4] + "****" + item.Phone[len(item.Phone)-4:]
	}

	// Computed status flag
	data["is_vip"] = item.TotalOrders > 50

	return data
}
```

## ⭐ Best Practices

1. **Keep Base Clean**: Never modify files inside `app/Resources/Base/` as they will be refreshed when running `go run cmd/padi/main.go g <table_name>`.
2. **Customize in Concrete Resources**: All field renamings, computed values, and relationship embeddings should be written in `app/Resources/<Name>Resource.go`.
3. **Consistent Output**: Always use `res.ToMap(item)` for single records and `res.ToMapCollection(records)` for slices.
